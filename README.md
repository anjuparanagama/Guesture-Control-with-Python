# AI Project

Simple Python project with a single entrypoint `main.py`.

## Description

A small script located in `main.py`. This repository contains the minimal code to run the project.

## Prerequisites

- Python 3.8 or newer
- (Optional) A virtual environment

## Setup

1. Create and activate a virtual environment (recommended):

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

2. If the project has dependencies, install them:

   ```powershell
   pip install -r requirements.txt
   ```

## Run

From the project directory run:

```powershell
python main.py
```
